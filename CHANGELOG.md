# Changelog

Todas as mudanças importantes deste projeto serão documentadas aqui.

## [1.0.0] - 2026-27-09

### Adicionado
- Versão inicial da extensão AutoForm Filler
- Detecção automática de campos de formulário
- Mapeamento universal por palavras-chave (fallback)
- Integração opcional com API DeepSeek
- Suporte às plataformas: Gupy, Oracle HCM, Comeet, Greenhouse, PinPeople
- Armazenamento local seguro via Chrome Storage API
- Interface de configuração no popup
